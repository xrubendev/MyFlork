# MyFlork

The wallet of the Flork ecosystem: a self-custody Solana wallet with the Florkverse inside
(flork.family, flork.fun, florkcoin.com, clans).

Flutter app for Android and iOS.

```bash
flutter run --dart-define=SOLANA_RPC=<relay url> --dart-define=FLORK_MINT=<mint>
```

`FLORK_MINT` stays empty until the FLORK launch (2026-12-03 21:00 UTC).
